# Financial Tracker (C++)

## Overview
Financial Tracker is a menu-driven C++ application that helps users record and manage income and expenses.

## Features
- Add income and expense transactions
- Display recorded transactions
- Calculate total income, total expenses, and current balance
- Search transactions by category
- Sort transactions by amount using Bubble Sort

## Concepts Used
- Classes and objects
- Constructors
- Arrays of objects
- Functions and encapsulation
- Linear search
- Bubble sort

## Technologies
- C++
- Standard Library (`iostream`, `string`)

## How to Run
1. Download or clone this repository.
2. Compile the source file using a C++ compiler:
   `g++ oopproject.cpp -o financial_tracker`
3. Run the compiled program:
   - Windows: `financial_tracker.exe`
   - Linux/macOS: `./financial_tracker`

## Limitations
- Transactions are stored in memory and are lost when the program exits.
- The application supports up to 100 transactions per run.
